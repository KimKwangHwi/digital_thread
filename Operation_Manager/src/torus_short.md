# Torus API 데이터 계층 및 컨텍스트 가이드

이 문서는 사용자 질문을 해결하기 위한 API 호출 계획을 수립하는 데 사용됩니다. API는 명확한 계층 구조를 가집니다.

---

## 1. 최상위 (Root)

### [시스템 / 장비 목록]
* **설명:** 시스템에 등록된 **모든 장비의 목록**을 조회합니다. (예: `get_machine_list`)
* **데이터 계층:** 없음. (모든 작업의 시작점이 될 수 있음)

---

## 2. 장비 레벨 (Machine Level)

장비 ID(`machine`)가 파라미터로 필요합니다.

### [장비 상태 및 기본 정보]
* **설명:** 특정 장비 1대의 **기본 명세**를 조회합니다. (예: NC 모델명, 제조사, 통신 상태, 메모리 용량 등)
* **데이터 계층:** `machine` ID 필요.
* **주요 정보:** 이 API를 통해 하위 계층에 필요한 **채널 개수(`numberOfChannels`)**를 파악할 수 있습니다.

### [채널 상태 정보]
* **설명:** 특정 장비의 각 **채널(계통)별 현재 상태**를 조회합니다. (예: 운전 모드(AUTO/MDI), 알람 상태, CNC 작동 상태)
* **데이터 계층:** `machine` ID, `channel` ID 필요.
* **주요 정보:** 이 API를 통해 하위 계층에 필요한 **축 개수(`numberOfAxes`)**, **스핀들 개수(`numberOfSpindles`)**, **공구 영역 번호(`toolAreaNumber`)**를 파악할 수 있습니다.

### [PLC 및 변수]
* **설명:** 특정 장비의 저수준 **PLC 메모리** (R, D 영역 등) 또는 **매크로 변수(#)** 값을 직접 조회합니다.
* **데이터 계층:** `machine` ID, (경우에 따라 `channel` ID), `variable` 주소 또는 `memory` 주소 필요.

### [센서 데이터 수집]
* **설명:** 특정 장비의 내장 **센서 데이터 수집(버퍼)** 상태 및 마지막 수집 값을 조회합니다.
* **데이터 계층:** `machine` ID, `buffer` ID 필요.

### [매거진 및 공구 목록의 공구 정보 (전체 목록 / toolArea)]
* **설명:** 특정 장비의 **전체 공구 영역(매거진)**에 등록된 **모든 공구의 목록**, 상태, 보정값, 수명 등을 T코드 또는 등록순 기준으로 조회합니다.
* **데이터 계층:** `machine` ID, `toolArea` ID 필요. (선행: '채널 상태 정보'에서 `toolAreaNumber` 확인)

---

## 3. 채널 레벨 (Channel Level)

장비 ID(`machine`)와 채널 ID(`channel`)가 모두 파라미터로 필요합니다.

### [축 상태 및 제어]
* **설명:** 특정 채널에 속한 각 **축(axis)**의 실시간 상태를 조회합니다. (예: 현재 위치, 부하, 이송 속도, 온도)
* **데이터 계층:** `machine` ID, `channel` ID, `axis` ID 필요. (선행: '채널 상태 정보'에서 `numberOfAxes` 확인)

### [스핀들 상태 및 제어]
* **설명:** 특정 채널에 속한 **스핀들**의 실시간 상태를 조회합니다. (예: RPM, 부하, 온도, 오버라이드)
* **데이터 계층:** `machine` ID, `channel` ID, `spindle` ID 필요. (선행: '채널 상태 정보'에서 `numberOfSpindles` 확인)

### [이송 속도 및 오버라이드]
* **설명:** 특정 채널의 **이송 속도** 및 **오버라이드** 비율을 조회합니다.
* **데이터 계층:** `machine` ID, `channel` ID 필요.

### [가공 상태 및 집계]
* **설명:** 특정 채널의 **생산 집계 정보**를 조회합니다. (예: 현재 가공 수량, 목표 수량, 총 절삭 시간)
* **데이터 계층:** `machine` ID, `channel` ID, `workStatus` ID 필요.

### [활성화된 공구 정보 (활성 공구 / activeTool)]
* **설명:** 특정 채널에서 **현재 활성화되어 사용 중인 공구 1개**의 상세 정보를 조회합니다. (예: T코드, 이름, 보정값, 수명)
* **데이터 계층:** `machine` ID, `channel` ID 필요.
* **참고:** '공구 정보 (전체 목록)' 카테고리와는 목적이 다릅니다.

### [NC 프로그램 실행 정보]
* **설명:** 특정 채널에서 **현재 실행 중인 NC 프로그램**의 상태를 조회합니다. (예: 프로그램 이름, 현재 블록(G/N코드), 모달 정보, 제어 옵션)
* **데이터 계층:** `machine` ID, `channel` ID 필요.

### [좌표계 및 오프셋]
* **설명:** 특정 채널의 **공작물 좌표계(G54-G59 등)**에 설정된 오프셋 값을 조회합니다.
* **데이터 계층:** `machine` ID, `channel` ID, `workOffset` ID 필요.

### [알람 및 에러]
* **설명:** 특정 채널에서 **현재 발생한 알람**의 상세 내용을 조회합니다. (예: 알람 번호, 내용, 발생 시각)
* **데이터 계층:** `machine` ID, `channel` ID, `alarm` ID 필요.
